# emoji-thumbnails

128×128 PNG renders of emoji glyphs that are newer than the `emoji-datasource-apple@16.0.0`
npm package (Unicode Emoji 17.0 and the subset of 18.0 that macOS can render), used as
thumbnails for the "All Emojis" dataset on Latent Lab. Files are named by lower-case
codepoints joined with `-`, excluding U+FE0F (e.g. `1faea.png`, `1faf9-1f3fb.png`).
Rendered from Apple Color Emoji on macOS; emoji artwork is © Apple Inc.
